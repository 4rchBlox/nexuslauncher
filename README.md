# NexusLauncher

Egy egyedi, stílusos Minecraft launcher Electron és Node.js alapokon, egyedi felhasználói felülettel és stílusos bejelentkezéssel.

## Főbb jellemzők
* Egyedi ablakkeret és sötét/Minecraft stílusú dizájn
* Felhasználónév alapú bejelentkezés
* Minecraft verzió választó
* Egyedi animációk és visszajelzések
